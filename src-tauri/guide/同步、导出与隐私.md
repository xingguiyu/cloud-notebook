# 同步、导出与隐私

![](assets/guide-sync.png)

不做任何设置时，笔记只在这台电脑上。下面的每一项都是可选的。

## 笔记放在哪

默认在「文稿 / Cloud Notebook」。在「设置 → 存储与同步」里可以换位置。

## iCloud Drive

在「设置 → 存储与同步」里把笔记库放进 iCloud Drive，同一个 Apple ID 的多台 Mac 会由系统自动同步。这是最省事的办法。

## Google Drive

需要在自己的 Google Cloud 项目里创建一个 OAuth 客户端，把客户端 ID 和密钥填进「设置 → 存储与同步」，然后登录。这样做是为了让数据只在你的电脑和你自己的 Google Drive 之间传输，不经过任何第三方服务器。

- 应用只能访问它自己在你的 Drive 里创建的文件，读不到其他文件。
- 两边都改了同一篇笔记时，会保留一份冲突副本，不会覆盖。
- 不想上传的笔记或文件夹，可以标成「仅本机」：点编辑器右上角的「发布与分享」按钮，在同步位置里选择。

同一个按钮里还可以把一篇笔记发布成 Google 文档，发给不用 Markdown 的人看。

## 加密笔记

右键笔记选「加密…」。加密后的笔记在磁盘上和云端都是密文，要输入密码才能看。

- 加密笔记有自己的密码，和证件夹的密码是分开的，在「设置 → 通用」里设置和修改，同样有一串恢复密钥要保存好。
- `⌥⌘L` 立即锁定所有加密笔记，也可以在「设置 → 通用」里设置自动锁定。
- 加密笔记不参与全文搜索。

## 导出

右键笔记选「导出…」，或者用菜单「文件 → 导出为」。

| 格式 | 适合 |
|---|---|
| PDF | 打印和发送，有几套排版模板 |
| Word | 给需要改稿的人 |
| HTML | 单个网页文件，图片内嵌 |
| Markdown 压缩包 | `.md` 加图片，打成 zip |
| Markdown（图床链接） | 贴到博客、公众号编辑器 |

`⌘P` 直接打印。

## 图床

在「设置 → 图床」里填自己的对象存储（S3、阿里云 OSS、腾讯云 COS 等）。之后右键笔记选「复制为 Markdown（图床链接）」，图片会上传并换成公开链接，适合把笔记贴到别处。

## 数据去了哪里

| 功能 | 发送什么 | 发给谁 |
|---|---|---|
| 同步 | 笔记文件 | 你自己的 Google Drive 或 iCloud |
| AI 助手 | 提问时相关的文字 | 你填了 Key 的那家服务商 |
| 图床 | 你选择上传的图片 | 你自己的对象存储 |
| AI 编程工具 | 项目文档，只在本机读写 | 应用本身不上传 |
| 检查更新 | 一个普通的网页请求，不带笔记内容 | GitHub（可在设置里关闭） |
| 统计 | 没有 | 没有 |
