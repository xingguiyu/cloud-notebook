# 整理与搜索

![](assets/guide-organize.png)

整理笔记有两种办法，可以一起用：文件夹和标签。

## 文件夹

侧边栏里的文件夹就是磁盘上的真实文件夹。

- `⇧⌘N` 新建文件夹；右键文件夹可以新建子文件夹、重命名、移到回收站。
- 把笔记从列表拖到文件夹上，或者右键笔记选「移动到文件夹」。

一篇笔记只能在一个文件夹里。适合按项目、按领域这种互不重叠的分法。

## 标签

在正文任意位置写 `#标签`，这篇笔记就有了这个标签。一篇笔记可以有很多标签。

- 用 `/` 分层：`#工作/周报`、`#工作/会议`，侧边栏里会折叠成一棵树。
- 标签写在哪里都行。在某个标签下新建笔记时会自动带上它，放在开头还是末尾可以在「设置 → 通用」里选。
- 输入 `#` 会出现已有标签的候选。

## 侧边栏顶部的几个视图

| 视图 | 里面是什么 |
|---|---|
| 全部笔记 | 所有笔记 |
| 未打标签 | 还没有任何标签的笔记，适合定期清理 |
| 待办 | 含有未完成待办的笔记 |
| 今天 | 今天修改过的笔记 |
| 已加密 | 加了密的笔记 |
| 回收站 | 删除的笔记，可以恢复 |

## 置顶、排序、多选

- 右键笔记选「置顶」，它会留在列表最上面。
- 列表右上角可以换排序方式；选手动排序后可以直接拖动笔记。
- `⌘` 点选多篇，`⇧` 点选连续一段，`⌘A` 全选。选中后右键，可以一起置顶、移动、加标签或删除。
- `Delete` 或 `⌘⌫` 把选中的笔记移到回收站。

## 搜索

按 `⇧⌘F`，输入要找的词。

- 搜的是全部笔记的全文，中文不用分词。
- 多个词用空格隔开，会找同时包含它们的笔记，标题命中的排在前面。
- 打开搜到的笔记，命中的词会高亮。
- 按 `Esc` 清空搜索。
