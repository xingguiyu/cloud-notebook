# 证件夹与项目密钥

![](assets/guide-vault.png)

侧边栏里的「证件夹」和「项目」用来保存不该写在普通笔记里的东西：密钥、账号、证件。里面的内容全部加密，要用密码或 Touch ID 解锁才能看。

## 第一次使用

第一次打开会让你设一个密码，并给你一串恢复密钥。

**请把恢复密钥抄下来，放在别处。** 忘记密码又没有恢复密钥，里面的内容谁也打不开，包括我们。

## 项目：密钥和文件按项目放

在「项目」里新建一个项目，把这个项目用到的东西都放进去：

- **大模型 Key**：粘贴 Key，应用会根据前缀认出是哪家的，自动填好接口地址和控制台链接。
- **接口 API Key**：可以记下环境（测试、正式）、App ID、文档地址。
- **账号**：后台、服务器、数据库。
- **证书和密钥文件**：把 `.p12`、`.pem`、`.mobileprovision` 之类的文件拖进来，应用会读出有效期、Team ID 等信息。

### 复制成 .env

打开一条大模型 Key 或接口 API Key，点「.env」按钮，会复制成这样：

```
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1
```

直接粘贴进项目的 `.env` 文件。

### 到期提醒

给密钥或证书填上「有效期至」。到期前 30 天内，应用会发系统通知提醒你，每天最多一次。项目列表里有东西快到期时会显示一个感叹号。

## 证件夹：个人证件

身份证、护照、银行卡、学历证书等都有现成的模板。

拍一张证件照片拖进来，应用会在本机识别上面的文字，自动填好姓名、号码、有效期。识别用的是系统自带的功能，照片不会上传。

## 安全是怎么做的

- 内容用 AES-256-GCM 加密。
- 密钥由你的密码经 Argon2id 算出来，只在这台电脑上。
- 支持用 Touch ID 解锁。
- AI 助手和 MCP 都读不到证件夹里的内容。
