# 写作与格式

![](assets/guide-writing.png)

编辑器是所见即所得的：输入 Markdown 记号，马上变成排好的样子。想看原始文本，按 `⌘/` 切到源码模式，再按一次切回来。

## 常用写法

| 想要 | 输入 |
|---|---|
| 标题 | `# ` 到 `###### `，或 `⌘1` 到 `⌘6`，`⌘0` 变回正文 |
| 粗体、斜体 | `**粗体**`、`*斜体*`，或 `⌘B`、`⌘I` |
| 高亮 | `==重点==` |
| 待办 | `- [ ] 要做的事` |
| 列表 | `- ` 或 `1. ` |
| 引用 | `> ` |
| 代码 | 行内用反引号，代码块用三个反引号加语言名 |
| 表格 | 工具栏里的表格按钮 |
| 链接到另一篇笔记 | `[[笔记标题]]`，输入 `[[` 会出现候选 |
| 标签 | `#标签` 或 `#标签/子标签` |

这些也都在编辑器上方的工具栏里。

一些实际的样子：

- [x] 待办长这样，点方框可以勾选或取消

> 引用的文字。

这是 ==高亮== 的效果，这是 `行内代码`。

```js
console.log('代码块会按语言着色')
```

## 图片

把图片拖进来，或者直接粘贴截图。图片保存在笔记旁边的 `assets` 文件夹里，笔记里是普通的 Markdown 图片语法。双击图片可以放大看。

从 Bear 复制内容粘贴过来，标题、列表和图片都会保留。

## 查找和替换

- `⌘F`：在当前笔记里查找
- `⌥⌘F`：查找并替换
- `⇧⌘F`：搜索全部笔记

## 让界面合你的意

- `⌘+` 和 `⌘-` 缩放编辑区，`⌥⌘0` 恢复原始大小。
- `⇧⌘\` 进入专注模式，只留编辑区。
- `⌘\` 显示或隐藏侧边栏，`⌥⌘\` 显示或隐藏笔记列表。两栏之间的分隔线可以拖动，双击恢复默认宽度。
- `⇧⌘I` 打开笔记信息：字数、大纲、创建和修改时间。
- 「设置 → 排版」调整字体、字号、行距，「设置 → 主题」有七套配色。

## 标题就是文件名

笔记的第一个一级标题会成为文件名。改标题，文件跟着改名。
