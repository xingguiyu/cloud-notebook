# Organizing and Searching

![](assets/guide-organize.png)

There are two ways to organize notes, and you can use both together: folders and tags.

## Folders

The folders in the sidebar are real folders on disk.

- `⇧⌘N` creates a folder. Right-click a folder to create a subfolder, rename it, or move it to the Trash.
- Drag a note from the list onto a folder, or right-click the note and choose "Move to Folder".

A note can be in only one folder. Folders suit groupings that don't overlap, such as by project or by area.

## Tags

Write `#tag` anywhere in the text, and the note has that tag. A note can have many tags.

- Use `/` for levels: `#work/weekly-report`, `#work/meetings`. The sidebar folds them into a tree.
- A tag can go anywhere. When you create a note under a tag, the tag is added automatically. You can choose whether it goes at the beginning or the end in "Settings → General".
- Type `#` to see suggestions from your existing tags.

## Views at the top of the sidebar

| View | What's in it |
|---|---|
| All Notes | Every note |
| Untagged | Notes that have no tags yet, good for regular cleanup |
| To-do | Notes with unfinished to-dos |
| Today | Notes modified today |
| Encrypted | Notes that are encrypted |
| Trash | Deleted notes, which can be restored |

## Pinning, sorting, multiple selection

- Right-click a note and choose "Pin" to keep it at the top of the list.
- Change the sort order at the top right of the list. With manual sorting selected, you can drag notes directly.
- `⌘`-click to select several notes, `⇧`-click to select a continuous range, `⌘A` to select all. Then right-click to pin, move, tag or delete them together.
- `Delete` or `⌘⌫` moves the selected notes to the Trash.

## Search

Press `⇧⌘F` and type what you are looking for.

- It searches the full text of all notes. Chinese text needs no word segmentation.
- Separate several words with spaces to find notes that contain all of them. Notes with a match in the title come first.
- Open a note from the results, and the matched words are highlighted.
- Press `Esc` to clear the search.
