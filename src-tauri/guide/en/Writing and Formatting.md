# Writing and Formatting

![](assets/guide-writing.png)

The editor is what-you-see-is-what-you-get: type Markdown marks and they turn into formatted text right away. To see the raw text, press `⌘/` to switch to source mode. Press it again to switch back.

## Common syntax

| You want | Type |
|---|---|
| Heading | `# ` to `###### `, or `⌘1` to `⌘6`; `⌘0` turns it back into body text |
| Bold, italic | `**bold**`, `*italic*`, or `⌘B`, `⌘I` |
| Highlight | `==key point==` |
| To-do | `- [ ] something to do` |
| List | `- ` or `1. ` |
| Quote | `> ` |
| Code | Backticks for inline code; three backticks plus a language name for a code block |
| Table | The table button in the toolbar |
| Link to another note | `[[Note title]]`; type `[[` to see suggestions |
| Tag | `#tag` or `#tag/subtag` |

All of these are also in the toolbar above the editor.

## Images

Drag an image in, or paste a screenshot directly. Images are saved in the `assets` folder next to the note, and the note uses ordinary Markdown image syntax. Double-click an image to see it larger.

When you copy content from Bear and paste it in, headings, lists and images are kept.

## Find and replace

- `⌘F`: find in the current note
- `⌥⌘F`: find and replace
- `⇧⌘F`: search all notes

## Make the interface yours

- `⌘+` and `⌘-` zoom the editing area; `⌥⌘0` restores the original size.
- `⇧⌘\` enters focus mode, leaving only the editing area.
- `⌘\` shows or hides the sidebar; `⌥⌘\` shows or hides the note list. You can drag the divider between the two columns, and double-click it to restore the default width.
- `⇧⌘I` opens note info: word count, outline, created and modified times.
- "Settings → Typography" adjusts font, font size and line spacing. "Settings → Theme" has seven color schemes.

## The title is the file name

The first level-one heading in a note becomes its file name. Change the title, and the file is renamed with it.
