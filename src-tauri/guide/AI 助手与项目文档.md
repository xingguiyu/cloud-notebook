# AI 助手与项目文档

![](assets/guide-ai.png)

这里有两件事：在应用里问 AI，以及让外面的 AI 编程工具把文档存进来。两件事都要你自己打开才生效。

## 在应用里问 AI

先在「设置 → AI」里填一家服务商的 API Key。支持 OpenAI、Anthropic、Gemini、DeepSeek、通义千问、OpenRouter，以及其他 OpenAI 兼容接口。Key 保存在系统钥匙串里。

按 `⌘J` 打开 AI 面板，上方可以选它参考什么：

- **整个笔记库**：从你的笔记里找出相关内容来回答，并标出引用了哪几篇。
- **当前笔记**：只根据打开的这篇回答，包括里面的图片。

选中一段文字再打开面板，可以直接让它总结、改写、续写或翻译。

只有你提问的时候，相关的文字才会发给你选的那家服务商。

## 让 AI 编程工具把文档存进来

用 Claude Code、Cursor 这类工具写代码时，它们会在仓库里留下计划、方案、设计文档。过一阵子就分不清哪份还算数。

Cloud Notebook 内置了一个 MCP 服务，让这些工具把文档直接存进笔记库里对应项目的文件夹。

### 接入

打开「设置 → 项目文档」，复制里面的命令，在终端里运行一次。

之后在任意仓库里对 AI 说：

- 「把这个方案存到 Cloud Notebook」
- 「整理一下这个仓库里的文档，导入 Cloud Notebook」
- 「Cloud Notebook 里这个项目现在有效的文档有哪些」

AI 第一次在某个仓库里保存文档时，会在「项目文档」下新建一个和仓库同名的文件夹。想用已有的文件夹，就在侧边栏右键它，选「绑定本地项目目录」。

### 文档状态

每份文档有一个状态：

| 状态 | 意思 |
|---|---|
| 当前有效 | 现在照这份做 |
| 草稿 | 写了，还没定 |
| 已被取代 | 有更新的一份替代了它 |
| 已归档 | 做完了，或者不做了 |

新文档取代旧文档时，旧的会自动标成「已被取代」。被取代和归档的文档默认收起，列表底部有一行可以展开。右键笔记选「文档状态」可以手动改。

状态写在文件开头的几行里，编辑器里不显示，文件本身仍然是普通的 Markdown。

### AI 能碰什么

- 只能读写已绑定项目的文档文件夹。
- 读不到你的其他笔记，碰不到证件夹。
- 导入是复制，仓库里的原文件不会被移动或删除。
- 「设置 → 项目文档」里可以关掉「允许 AI 写入」，关掉后它只能读。

## 版本历史

每篇笔记都有历史版本，不只是 AI 存进来的文档。

右键笔记选「版本历史…」，可以看到之前的内容，和现在逐行对比，或者恢复到某一版。恢复之前的内容也会留在历史里，可以再恢复回来。

笔记被修改时自动保存修改前的内容，连续编辑时最多每十分钟留一份。历史版本只保存在这台电脑上，不参与同步。
