# 欢迎使用 Cloud Notebook

![](assets/guide-welcome.png)

Cloud Notebook 是一个写 Markdown 的笔记本。这几篇指南会带你把它用起来，随时可以回来查。不需要的时候，把整个「Cloud Notebook 指南」文件夹移到回收站就行；想找回来，在菜单栏选「帮助 → 使用指南」。

## 它是怎么想的

**笔记是你的文件。** 每篇笔记是磁盘上的一个 `.md` 文件，侧边栏里的文件夹就是磁盘上的文件夹。没有专有格式，没有数据库把内容锁在里面。哪天不用 Cloud Notebook 了，笔记还在原处，用任何编辑器都能打开。

**笔记和它提到的东西放在一起。** 做项目时，笔记里会写到 API Key、账号、证书。它们加密保存在旁边的证件夹里，不用再去别的应用里翻。

**默认不联网。** 同步、AI、图床都要你自己打开才生效，数据从这台电脑直接发给你选的服务。应用没有账号系统，没有统计代码。

**给 AI 写的文档一个去处。** 用 AI 写代码会留下很多计划和方案。它们可以直接存进对应项目的文件夹，并标明哪一份现在有效。

## 从这里开始

1. [[写作与格式]]：Markdown、快捷键、图片、查找替换
2. [[整理与搜索]]：文件夹、标签、置顶、全文搜索
3. [[证件夹与项目密钥]]：保存密钥和证件，复制成 `.env`
4. [[AI 助手与项目文档]]：问 AI、接入 Claude Code 和 Cursor、版本历史
5. [[同步、导出与隐私]]：Google Drive、iCloud、导出、加密笔记

## 三件马上能做的事

- 按 `⌘N` 新建一篇笔记，第一行就是标题。
- 在正文里写 `#想法`，侧边栏会出现这个标签。
- 按 `⇧⌘F` 搜索全部笔记。
